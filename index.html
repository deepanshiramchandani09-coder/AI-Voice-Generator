Quick Setup & Configuration

  1. Get your API Key: Sign up or log in at elevenlabs.io, click your Profile icon in the bottom-left > API Keys, and create/copy your key.
  2. Configure .env: In the project folder, make a copy of .env.example named .env and add: 
    ELEVENLABS_API_KEY=sk_your_actual_elevenlabs_api_key
  3. Start the backend: Run npm start in your terminal. Open http://localhost:3000 in your browser.
  4. Generate audio: Pick a voice, select a model, type your text, and click Generate & Play Speech!
